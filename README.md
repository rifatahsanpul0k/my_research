# spatial-omics-auto

Fully automated unsupervised spatial multi-omics research, run by a local
Antigravity agent on PULOK's Mac, with Phoenix (Muse) as the async research partner.

**Start here:** `HANDOFF.md` — the collaboration protocol. The agent reads it first, every session.

- `briefs/` — Phoenix → agent (specs, decisions, feedback). Newest brief rules.
- `runs/<stage>/<exp_id>/` — agent → Phoenix (result folders after every run).
- `reports/REPORT-<stage>.md` — agent's per-stage analysis. This is what Phoenix reviews.

First brief: `briefs/BRIEF-001-research-brief.md`.
